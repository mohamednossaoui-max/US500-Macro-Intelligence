عند مراجعة النسخة المصححة السابقة وإعادة تشغيل الحساب بعينة ثابتة أعدنا إنتاج عيب مؤكد:

أضيف أيضًا:
- اختبار فعلي لدالة الحساب ولـmain بدل الاكتفاء بفحص ملفات منشورة سلفًا.
- تشغيل معزول للمراحل الثلاث، مع استبدال جلب الشبكة بمدخلات اصطناعية ثابتة في الاختبارات فقط. الجلب الحقيقي ما زال يستخدم المصادر الأصلية.
- تسجيل stdout/stderr لكل مرحلة داخل artifact باستخدام tee مع pipefail؛ لا يُخفى exit code عند حفظ السجل.
- ملخص يبين المرحلة الفاشلة ونتيجة كل خطوة وروابط ملفات السجل والنطاق المطلوب والمتاح. لا يتحول تقرير PASS قديم إلى نجاح لتشغيل فاشل، ولا يصبح النص False قيمة تحقق صحيحة.

```bash

```

يبقى تصنيف STALE عندما يتوقف مصدر العضوية قبل النطاق المطلوب. هذا الإصلاح يعالج خطأ التنفيذ والتشخيص؛ لا يختلق بيانات عضوية جديدة ولا يمنح البيانات صفة PIT-perfect.

للرجوع عن التصحيح، اعمل Revert لــcommit هذه الملفات الأربعة فقط. آخر البيانات المنشورة لا تتغير عند تطبيق الحزمة.
