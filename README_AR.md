إضافة Fed إلى Evidence Attention مع توضيح Decision State

هذه حزمة تعديل محدد تطبق على app.py الحالي، ولا تتضمن نسخة app.py قديمة تستبدل تغييراتك الجديدة.

طريقة الدمج:
1. نزّل ZIP حديثًا لمشروعك من GitHub وفكّه.
2. انسخ executive_attention_v1.py ومجلدي scripts وtests من هذه الحزمة إلى مجلد المشروع، مع دمج المجلدات والحفاظ على بقية الملفات.
3. من مجلد المشروع الذي يحتوي app.py نفّذ:
   python scripts/apply_fed_attention_ui_v1.py
   في Windows يمكن استخدام py بدل python إذا كان هذا هو الأمر المثبت.
4. تظهر رسالة Updated app.py، وتُحفظ نسخته الأصلية باسم app.py.before-fed-attention.bak.
5. ارفع app.py الناتج وexecutive_attention_v1.py إلى جذر مستودع GitHub. أضف ملف الاختبار إلى tests إن أردت تضمينه في اختبارات المستودع. لا ترفع النسخة الاحتياطية. سكربت التعديل لا يلزم لتشغيل Streamlit بعد تطبيقه.
6. لا تحتاج تشغيل Autonomous لتعديل العرض وحده؛ افتح Executive Dashboard بعد تحديث نشر Streamlit.

يتوقف السكربت دون تغيير app.py إذا اختلف موضع القائمة عن الهيكل المتوقع. في هذه الحالة أرسل app.py الحالي لتجهيز تعديل مطابق. لا تحذف أو تستبدل بقية ملفات المشروع.

ما يظهر:
- بند Fed Intelligence (current) مع تصنيف Fed الفعلي ودرجته وتاريخ as_of_date وبوابة الجودة وحداثة التحقق وحالة PIT المنشورة.
- البند موسوم CONTEXTUAL ولا يدخل في قرار V1 أو أصواته. لا نستنتج أن hawkish أو dovish يساوي supportive/contradictory آليًا.
- عند غياب Fed يظهر UNAVAILABLE دون اختلاق درجة.
- تحت القائمة أعداد CORE الداعمة والمعارضة والمختلطة، وشرح لماذا SUPPORTIVE لا تعني اتفاق معظم المكونات.
- لا إعادة حساب Decision State أو تغيير الأوزان أو CORE/PIT أو إدخال Fed في التصنيف.

سبب الصورة:
الكود الحالي MIN_EVIDENCE=2. إذا وُجد دليل داعم واحد ولم يوجد دليل معارض يصنف SUPPORTIVE، ولو كانت بقية الأدلة MIXED. وعند وجود اتجاهين يستخدم نسبة الداعم إلى (الداعم+المعارض)، مستبعدًا MIXED من المقام. MAJORITY_RATIO=0.67. Evidence Coverage=1.00 عند اكتمال أربعة أدلة أو أكثر؛ ليست نسبة الداعمين أو احتمال الصعود. يمكن مناقشة قاعدة أكثر تحفظًا كتغيير مستقل؛ لم نغير الحساب في هذا التعديل.

الاختبارات:
11 اختبارًا ناجحًا على Python 3.12.14، تشمل استدعاء classify_evidence الفعلية من النسخة المتاحة بحالة الصورة، ثبات المدخلات، سياق Fed، غياب المصدر وتدهور الجودة، وعدم تغيير أي كود تنفيذي خارج executive والإضافة المستوردة. اختُبرت أداة الدمج على نسخة مؤقتة وتكرار تشغيلها، وتأكدت سلامة AST بصياغة Python 3.11؛ هذا فحص صياغة وليس تشغيلًا على مفسر 3.11.

استعد app.py من app.py.before-fed-attention.bak، ثم احذف executive_attention_v1.py وملف الاختبار الجديد إن رغبت.
