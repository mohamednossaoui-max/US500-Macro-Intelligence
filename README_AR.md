# تجربة مقارنة أدلة Fed — الإصدار الأول

هذه إضافة بحثية مستقلة إلى جانب المشروع، وليست تحديثًا منشورًا للوحة Streamlit.
لا تستبدل أي ملف أصلي، ولا تُستورد من app.py أو مسار النشر. لا تضيف Fed إلى
Decision Engine ولا تغيّر الأوزان أو Decision State أو System Health.

## التشغيل

فك الحزمة داخل جذر المشروع، ثم شغّل الأمر التالي. يعمل البرنامج بمكتبة Python
القياسية، دون تثبيت تبعيات أو إجراء اتصالات شبكة:

```bash
python experiments/fed_evidence_v1/fed_evidence.py
```

النتيجة الافتراضية DISABLED، دون قراءة المدخلات أو كتابة تقرير. لتشغيل المثال:

```bash
python experiments/fed_evidence_v1/fed_evidence.py --enable --input experiments/fed_evidence_v1/demo_input.json --as-of 2026-10-30T09:00:00Z
```

افتح `experiments/fed_evidence_v1/output/report.html` في المتصفح. يحتوي التقرير
على عمودين للسابق والحالي، والأرقام والدليل النصي، وتفاصيل المصدر والتوقيت والنسخة.
ملف report.json يحتوي المخرجات نفسها بصيغة قابلة للفحص.

**المثال توضيحي فقط:** يستخدم مقتطفات مختصرة وأوقات رصد مصطنعة، وموسوم synthetic.
لا يُستخدم في دراسة أحداث أو اختبار تاريخي، ولا يدل ظهوره على نشر بيانات جديدة
داخل التطبيق. النسخة الحالية ليست مجمّع بيانات حيًا.

## ما الذي تختبره الإضافة؟

- فصل الفعل الرسمي HOLD / RAISE / CUT عن النطاق والتصويت واتجاه الاعتراضات.
- الاحتفاظ بالنص الداعم، بما فيه أسماء ذات أحرف أولى مثل Lisa D. Cook.
- إبقاء النمو والتضخم والتوجيه والظروف المالية كنصوص أدلة، دون درجة نبرة جديدة.
- إبقاء غياب المعلومة مجهولًا، وتمييز الاعتراضات المتعاكسة.
- مقارنة وثيقتين من النوع نفسه: OFFICIAL_STATEMENT أو OPENING_STATEMENT.
- الاحتفاظ بوسم PRELIMINARY أو FINAL أو UNKNOWN لكل نسخة.

النص الكامل للأسئلة والأجوبة غير مدعوم في هذه المرحلة، ويُرفض صراحة لمنع إسناد
أسئلة الصحفيين إلى Fed. لا تستنتج الإضافة تلقائيًا أن tightened تعني أن المستوى
tight؛ تعرض الدليل النصي للمراجعة البشرية. لا تقترح إشارة تداول أو تدّعي edge.

## إدخال بيانات حقيقية

أنشئ manifest على نمط demo_input.json مع synthetic=false، وأضف لكل وثيقة:
text وsha256 وmeeting_date وfirst_seen_at وsource وscope وversion_status.
استعمل مصدرًا رسميًا HTTPS من www.federalreserve.gov. sha256 هو بصمة UTF-8
للنص المدخل؛ يثبت سلامة هذا النص فقط، ولا يثبت أصالة الوثيقة أو اكتمالها.

first_seen_at توقيت الرصد الموثّق لهذه النسخة بالتحديد، مع منطقة زمنية صريحة.
published_at اختياري، ولا يُستخدم لإرجاع نسخة ملتقطة لاحقًا إلى وقت سابق. عند
وجود نسخة منقحة أضف سجلًا جديدًا بتوقيت رصدها وبصمتها، ولا تستبدل السجل القديم.
إذا لم تحفظ نسخة وقت الحدث فلا تخترع لها وقت إتاحة تاريخيًا. التاريخ وحده مرفوض
كوقت إتاحة. هذا التحفظ قد يؤخر إتاحة وثيقة عن وقت نشرها الحقيقي؛ وهو مقصود.

تعتمد بوابة التجربة على صدق سجلات الرصد المدخلة، ولا توثقها تشفيريًا مع جهة
خارجية. احتفظ بأرشيف المصدر أو إيصالات الالتقاط للمراجعة. لا تنقل published_at
الخاص بالبيان إلى المؤتمر أو SEP أو المحاضر أو Beige Book.

## حدود التنفيذ والرجوع

هذه أول تجربة فقط من المقترحات الثلاثة؛ تجارب GDP/PCE والسيولة غير منفذة هنا.
لا يوجد دمج مع Evidence Attention أو تعديل لمنطق وصف SUPPORTIVE في هذه الحزمة.
يظل محلل النص محدودًا بالصيغ الصريحة المدعومة، ويحتاج مراجعة بشرية عند غياب حقل.
للتراجع احذف مجلد experiments/fed_evidence_v1 فقط. لا يلزم إعادة نشر التطبيق.

لتشغيل اختبارات القبول عند توفر pytest:

```bash
python -m pytest -q -p no:cacheprovider experiments/fed_evidence_v1/test_fed_evidence.py
```

اختبارات القبول تغطي حد التوقيت، المراجعات، بصمة النص، اختلاف النطاق، الاعتراضات،
عدم تغيير المدخلات، مناطق التوقيت، وإفلات HTML. هذه اختبارات سلامة للتجربة،
وليست إثباتًا لجودة تنبؤ أو اختبارًا شاملًا للتطبيق.
