# US500 Macro Intelligence — Public Research Data

Automatically published research datasets.

## Research-only

This data layer is:

- Research only
- No trade execution
- No broker integration
- No position sizing
- No SL/TP generation
- No deterministic market prediction

The Streamlit terminal reads this directory directly.

A personal GitHub token is not required.

`manifest.json` contains SHA-256 checksums for published files.
